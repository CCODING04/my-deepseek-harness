# @deepseek-ai/dsh-client-ui-settings-remote-access

English | [中文](README.zh.md)

Web 设置中的**远程连接**控制页:隧道状态、启动/停止/重启、公网 URL 与凭据管理。

## 功能

浏览器插件注册一个本地化的 `settings.section` 贡献,id 为 `remote-access`(排在"通用设置"之后)。该页面经 [`api-remotes`](../../api/remotes/README.md) 装配调用 Host 的 [`remoteAccess`](../../host/remote-access/README.md) 命名空间:

- **状态卡片** — 带彩色圆点的生命周期状态(已停止/启动中/运行中/错误)、运行时的公网 URL(含复制/打开操作)、平台键、cloudflared 二进制是否就绪。
- **控制** — 启动 / 停止 / 重启按钮;运行或启动期间每 4 秒轮询一次,保持 URL 与状态新鲜。
- **配置** — 代理端口、上游端口、用户名、密码作为暂存草稿字段,保存后写入;端口修改在下次启动时生效。
- **凭据** — 用户名/密码回显,以及"重新生成密码"按钮(写入空 `pass`,由 Host 替换为新密钥)。

草稿在点击保存前不会提交,因此中途离开页面不会写入半截编辑。加载与失败状态保持在组件内部,并提供重试。

## Model Experience

无——本包只从浏览器设置页控制 Host 拥有的进程面,不注册任何模型相关能力。

#### KV Cache effect

无;本包既不组装也不发送 provider 请求。

## 已知限制与后续工作

- **停止状态下不自动刷新** — 仅隧道运行/启动期间轮询;停止时显示最后快照,直到重新挂载或按下控制按钮。
- **凭据明文显示** — 密码字段是可编辑文本(非掩码 secret 输入),配合"复制到手机"工作流;掩码切换作为后续工作。
